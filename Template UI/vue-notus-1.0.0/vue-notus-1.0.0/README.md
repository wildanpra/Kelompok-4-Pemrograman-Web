# Vue Notus - A free Tailwind CSS and VueJS UI Kit and Admin by Creative Tim.

#### Preview

 - [Demo](https://themewagon.github.io/vue-notus/)

#### Download
 - [Download from ThemeWagon](https://themewagon.com/themes/vue-notus/)

## Getting Started

1. Clone Repository
```
git clone https://github.com/themewagon/vue-notus.git
```
2. Install Dependencies
```
npm i
```
3. Run the development server:

```bash
npm run serve
# or
yarn serve
# or
pnpm serve
# or
bun dev
```
